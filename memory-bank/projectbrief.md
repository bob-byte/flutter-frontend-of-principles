# Project brief

**Principles** is a Flutter rewrite of the Principles habit/goal app (with a .NET backend in `backend/`).

Core loop: users set **goals**, attach **habits** that automate progress toward those goals, use **tasks** to remember one-off work and keep habits visible, and get support from an **AI Helper**. Settings (profile, slogan, mission) feed AI habit recommendations.

Official install page: https://principles.top
