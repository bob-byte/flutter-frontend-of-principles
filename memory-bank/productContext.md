# Product context

## Why

Help people achieve goals by turning them into repeatable habits and daily follow-through, with tasks for everything habits do not cover.

## How it should work

1. Define a goal
2. Add habits under that goal (optionally via AI recommendations)
3. Complete habits consistently; inspect detail (progress, streaks, stability)
4. Use Tasks for reminders and to keep today's habits obvious
5. Use AI Helper for support (habits, goals, scheduling) — not as the primary recommendation entry point
6. Tune profile / theme / language in Settings; replay the in-app road guide from About

## UX notes

- Pre-login: App Benefits carousel (unchanged marketing)
- Post-login: spotlight road guide once per device; replayable from Settings
- Tab order: Chat · Goals · **Tasks** (center) · Habits · Settings
